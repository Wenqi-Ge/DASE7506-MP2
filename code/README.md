# Code structure

The frozen submission entry point is `submission_v73.py`, with matching assets in `artifacts/v73/checkpoint`. The integrity manifest verifies the submitted source and matching deployed assets. The package root README provides complete setup, training, evaluation and report commands.

| Module | Main responsibility |
|---|---|
| `reference_rebuild_v73/maths.py` | Bounded exact numeric evaluation, equation parsing and repair propagation |
| `reference_rebuild_v73/features.py` | Canonical answer grouping and rich, compact, quantity, schema, repair and lexical features |
| `reference_rebuild_v73/stack.py` | Question-preserving augmentation, five linear views, OOF meta features and lexical training |
| `reference_rebuild_v73/net.py` | PyTorch self-attention scorers used during training only |
| `reference_rebuild_v73/train.py` | TRAIN/validation fitting, model export, fusion selection and pre-test freeze |
| `reference_rebuild_v73/runtime.py` | NumPy-only tree/attention inference, probability fusion and same-answer mean selection |
| `reference_rebuild_v73/verify.py` | Freeze checks and fresh-process official evaluation with four numerical threads |
| `reference_rebuild_v73/audit_runtime.py` | NumPy-only validation deployment and input-contract checks |
| `reference_rebuild_v73/audit_training.py` | Replay fitting statistics and OOF predictions from a full training output |
| `report_analysis.py` | Validation-only tables, fixed ablations, examples and score-gap diagnostics |
| `resource_audit.py` | Asset accounting and fresh validation thread/GPU-library inspection |
| `majority_baseline.py` | Training-free answer-frequency baseline |
| `verify_release.py` | Release inventory and deployed model integrity |

`common.py`, `predict.py`, `score_predictions.py` and `check_data.py` are unchanged official tools. Inference needs only NumPy; PyTorch, scikit-learn, SciPy and CatBoost are training dependencies. `runtime.py` does not import the training pipeline or read report/experiment probabilities.

All learned inference assets reside in the checkpoint directory. The saved `validation-components.npz` outside that directory supports analysis only. Training-only search caches are regenerated by `train.py`; they were omitted from this submission package. Run `audit_training.py` against a fresh full training output such as `artifacts/retrained-v73`, rather than the slim provided `artifacts/v73` directory.
